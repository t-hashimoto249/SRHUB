# 目的
このプロジェクトはステージレースと呼ばれる、複数日かけて250km等を走るマラソン大会を盛り上げるために大会の紹介や走った人のレポート等を興味がある方に届けることを目的とします。

# ターゲット読者
- メインターゲット: ランナー、特にウルトラマラソンやトレイルランニングなど、通常のマラソンより過酷なレースを走っている層
- 想定する関心: 次に挑戦するレースを探している、海外大会の情報を知りたい、経験者のリアルな声を読みたい

# 提供コンテンツ
世界中で開催されているステージレースを軸に、以下の情報を提供する。

- レース紹介
  - レース概要（開催地、距離、ステージ構成、難易度、開催時期 など）
  - 持ち物・装備リスト
  - スケジュール（日程、ステージごとの行程）
  - 参加までの流れ（エントリー方法、必要書類、渡航・現地手配の概要）
  - 公式ホームページへのリンク
- 参加レポート（実際に走ったランナーの体験記）
- 動画紹介（YouTube などの関連動画の埋め込み・キュレーション）

# 機能要件

## レース検索・絞り込み
レース一覧ページから、以下の軸で絞り込み・検索ができること。主軸は「国」とする。

- 国（一次導線）／大陸
- 距離（例：150km、250km、350km など）
- 開催時期（月）
- 環境・地形（砂漠／山岳／極地／ジャングル など）
- 難易度
- サポート形態（セルフサポート／フルサポート）
- 運営団体
- 参加者数（おおよその規模）
- 参加費

なお、MVP 公開時点では絞り込み UI は実装せず一覧表示のみとし、データスキーマは上記すべてに対応した形で最初から定義する（絞り込み UI は MVP 後に追加）。

## レポート運用
- レポートは一般ユーザーから直接投稿できる形式ではなく、運営（編集者）が原稿を確認・編集したうえで公開する編集型とする
- 寄稿者からの原稿受付フローは別途検討（メール／フォームなど）

## レポートの目的別分類
レポートは「ランナーが何を目的にレースに参加したか」で分類し、読者は自分の目的に近いレポートを参照できるようにする。

| 値（key） | 表示ラベル | 想定読者 |
| --- | --- | --- |
| `completion` | 完走志向 | 制限時間内に走り切ることを目標とするランナー |
| `competitive` | 上位志向 | タイム・順位を狙う経験豊富なランナー |
| `personal` | マイペース志向 | 写真・観光・自分なりのテーマを持って楽しむランナー |

- 1 レポート = 1 目的（複数選択不可）
- レース詳細ページでは、目的別に切り替え／フィルタ可能な UI でレポート一覧を表示する

## レポートの本文構成（テンプレート）
すべてのレポートは以下の見出し構成に統一し、目的別の比較がしやすいようにする。テンプレートファイル `content/reports/_template.md` を提供。

1. **導入文**（何を目指して参加したか／結果サマリー）
2. **## 練習・準備**（トレーニング計画、現地適応）
3. **## 装備**（持参した装備リスト、選択理由、感想）
4. **## 食事・補給**（カロリー設計、行動食、現地食）
5. **## レースレポート**（各ステージの様子、トラブル対処）
6. **## 振り返り**（完走後の感想、後続へのアドバイス）

## レース・レポート・動画の紐付け
- 各レースの詳細ページに、そのレースの「参加レポート一覧」と「関連動画（YouTube 等）」を自動的に表示する
- 各レポートには寄稿者のプロフィール情報（氏名／ハンドル、簡単な紹介、SNS／連絡先など）を表示する
- 寄稿者専用のプロフィールページは設けない（レポート内に表示する範囲でよい）

## 寄稿者への問い合わせ
- 読者が寄稿者に直接コンタクトできる導線を用意する
- 連絡手段は SNS リンク または メールアドレス（寄稿者が選択した手段を表示）
- サイト内に独自のメッセージ機能は持たない（外部リンク・mailto で完結）

## 多言語対応
- 日本語のみ。日本人ランナー向けのサイトとする

# 非機能要件
- デバイス対応：スマホ／PC のレスポンシブ対応。スマホファーストで設計する
- SEO：重要視する。「ステージレース ◯◯」等の検索で日本人ランナーに見つけてもらえることを目標とする
  - 静的生成によるレンダリング、適切なメタタグ・OGP、構造化データ、サイトマップ、内部リンク設計を行う
- アクセシビリティ：特に意識した対応は行わない（最低限のセマンティック HTML に留める）
- 想定アクセス規模：当初は月数千 PV 程度

# 技術・運用要件

## 体制・更新頻度
- 編集者は橋本氏 1 名
- 更新頻度は月数回程度

## コンテンツ管理方式
- 静的サイト + Markdown 方式を採用
  - フレームワーク：**Next.js**
  - 原稿は Git リポジトリで Markdown（MDX）ファイルとして管理
  - 画像はリポジトリ内 `public/` 配下で管理（量が増えたらオブジェクトストレージへ移行を検討）
- レース・レポート・寄稿者・動画はそれぞれ Markdown + フロントマターでデータ化し、ビルド時に紐付ける

## デザイン
- Claude Design で UI を作成

## ホスティング・ドメイン
- ホスティング：Vercel（Next.js との相性、無料枠を考慮）
- ドメイン：これから取得（即日対応可）

# データスキーマ

コンテンツは `content/` 配下に Markdown + フロントマターで管理する。

## レース（`content/races/<slug>.md`）

```yaml
---
title: サハラマラソン                       # 日本語表記
title_en: Marathon des Sables              # 英語名（SEO・公式名称）
slug: marathon-des-sables                  # URL 識別子
country: モロッコ                            # 絞り込み軸（一次）
continent: アフリカ                          # 絞り込み軸
distance_km: 250                           # 総距離
stages: 6                                  # ステージ数
duration_days: 7                           # 開催日数
start_month: 4                             # 開催月（1-12、絞り込み軸）
terrain: [砂漠]                             # 配列。砂漠／山岳／極地／ジャングル など
difficulty: 5                              # 1〜5
support: self                              # self / full
organizer: AOI Sports                      # 運営団体
participants_approx: 1200                  # 参加者数の概数
entry_fee:
  amount: 3500
  currency: EUR
official_url: https://...                  # 公式サイト
hero_image: /images/races/mds-hero.jpg
summary: 世界一過酷とも言われる…             # 一覧カード／OGP 用の短い説明
gear:                                       # 装備リスト
  - 必携：シュラフ、ヘッドランプ…
  - 推奨：…
schedule:                                   # スケジュール
  - day: 1
    description: 33km、丘陵地帯
  - day: 2
    description: 38km、砂漠
entry_flow: |                               # 参加までの流れ（Markdown）
  1. 公式サイトでエントリー
  2. 健康診断書の提出
  3. 渡航手配
videos:                                     # 関連動画（YouTube、複数可）
  - id: dQw4w9WgXcQ
    title: 2024 年大会ハイライト
  - id: abc123XYZ
    title: 公式プロモーション映像
---

ここからレース本文（Markdown）を自由に記述。
```

## レポート（`content/reports/<slug>.md`） — MVP 後

```yaml
---
title: 2024 年サハラマラソン参加記
slug: mds-2024-hashimoto
race_slug: marathon-des-sables             # 紐付くレース
contributor: hashimoto                      # 寄稿者 ID
date: 2024-04-15
hero_image: /images/reports/mds-2024-hashimoto.jpg
summary: 砂嵐の中、6 日間 250km を走り切った記録
---

レポート本文。
```

## 寄稿者（`content/contributors/<id>.md`） — MVP 後

```yaml
---
id: hashimoto
name: 橋本 健志
bio: 国内外のステージレースに 5 戦完走。…
avatar: /images/contributors/hashimoto.jpg
contacts:                                  # 複数指定可。順番に表示
  - method: email                          # email / x / instagram / youtube / facebook / website
    value: hashimoto@example.com
  - method: instagram
    value: https://instagram.com/...
---
```

# 公開・将来拡張

## MVP（最小公開版）
- 公開目標：来週（要スケジュール調整）
- 含めるもの：
  - レース紹介ページ 5〜10 件
  - 検索・絞り込み（国を主軸とする最低限の絞り込み）
  - サイト基本構成（トップ、レース一覧、レース詳細、About）

  - 参加レポート機能
  - 動画紹介機能
  - 全絞り込み軸（距離、時期、環境、難易度、サポート形態）の実装
  - 寄稿者の問い合わせ導線
  - SEO 強化（構造化データなど）
